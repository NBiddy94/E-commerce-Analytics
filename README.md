# E-commerce-Analytics
https://docs.google.com/spreadsheets/d/1kqMpD_ZDcdj1QA7paGOUIhHT0Ahof1tqoLWrjqM8v70/edit?usp=sharing
Built a conversion funnel by creating pivot tables that revealed the number of users that convert from each stage of a sale to the next. This showed the conversion rate between stages. Preprocessed data using filters, pivot tables, and vlookups to prepare it for analysis.  Calculated customer retention rates after specific actions were made.
